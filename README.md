## 🚀 Функционал

| Модуль | Описание |
|--------|----------|
| 🔐 **Аутентификация** | Регистрация, вход, JWT-токены |
| 🤖 **AI-помощник** | Чат с интеграцией Groq API |
| 🔍 **Поиск событий** | Концерты, театр, спорт, кино, выставки, квесты |
| ❤️ **Избранное** | Сохранение понравившихся событий |
| 👤 **Личный кабинет** | Управление профилем |
| 🌍 **Мультиязычность** | Русский, белорусский, английский |
| 🗺️ **Карта** | OpenStreetMap с геолокацией событий |
| 📅 **Парсинг** | Автоматический сбор событий раз в неделю |
